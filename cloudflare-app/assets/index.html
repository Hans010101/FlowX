为什么没有平台同步发布？

Wechatsync 依赖你电脑浏览器里的平台 Cookie 和扩展会话，Cloudflare 无法持有这类本地登录态。云端完成稿件后，可复制到平台后台，或继续使用 GitHub 中的本地完整版同步到草稿箱。

安全

整个工作台受独立密码保护。API Key 使用 AES-GCM 加密后存入 D1，解密密钥只存在 Cloudflare Worker Secret 中，不进入代码仓库。

API 设置

留空表示保留已有 Key。Key 会在 Worker 内加密后写入 D1，界面永不回显原值。
